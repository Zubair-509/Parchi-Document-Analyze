# Parchi UI — Design & Development Specification

Complete reference for recreating this project exactly. Clone → install → run should give you an identical result.

**Repo:** https://github.com/Robo-Hanan/parchi-ui

---

## 1. What This Is

Parchi is an AI-powered prescription explainer for Pakistani patients. This repo is the **frontend UI only** — landing page, auth flow, and three post-login app pages. There is no real backend wired in yet; auth and AI analysis are mocked.

---

## 2. Clone & Run

```bash
git clone https://github.com/Robo-Hanan/parchi-ui.git
cd parchi-ui
npm install
npm run dev
```

Runs at `http://localhost:5173`.

## 5. Design System

### Fonts
Loaded via Google Fonts in `index.html`:

```html
<link href="https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@9..144,500;9..144,600;9..144,700;9..144,900&family=Lexend:wght@400;500;600;700;800&family=Noto+Nastaliq+Urdu:wght@400;700&display=swap" rel="stylesheet" />
```

| Font | Variable | Use |
|---|---|---|
| Fraunces | `--font-display` | Headings, wordmark |
| Lexend | `--font-body` | Body text (default) |
| Noto Nastaliq Urdu | `--font-urdu` | All Urdu text (RTL) |

### Color Tokens
Defined in `src/index.css` under `:root`:

```css
--bg-deep:    #050a08   /* page background */
--bg-card:    #0d1713   /* cards, sidebar, panels */
--sage:       #5a8a6e   /* primary accent — buttons, active states */
--sage-deep:  #3d6b5c   /* sage hover state */
--forest:     #2d5145   /* darker green accent */
--cream:      #fbf7f2   /* primary text, headings */
--coral:      #e8826b   /* warnings, pricing highlights, side effects */
--text-muted: #9cc2a6   /* secondary text */
```

### Tailwind v4 Theme
Registered in `src/index.css` via `@theme` block (not `tailwind.config.js`):

```css
@import "tailwindcss";

@theme {
  --font-display: 'Fraunces', Georgia, serif;
  --font-body: 'Lexend', system-ui, sans-serif;
  --font-urdu: 'Noto Nastaliq Urdu', serif;
}
```

### Urdu Text Rule
Every Urdu string uses the `.urdu` class + cream color + text shadow:

```jsx
<p className="urdu text-[var(--cream)]"
   style={{ textShadow: '0 2px 16px rgba(5,10,8,0.85)' }}>
  اپنا نسخہ سمجھیں۔
</p>
```

`.urdu` is defined in `index.css`:
```css
.urdu {
  font-family: var(--font-urdu);
  direction: rtl;
  line-height: 2.2;
}
```

### Glitch Title
Used in the Hero for "PARCHI". Class `.glitch-title` with `data-text` attribute:
```jsx
<h1 className="glitch-title" data-text="PARCHI">PARCHI</h1>
```
The CSS uses `::before` / `::after` pseudo-elements with chromatic aberration clip-path animations (coral + sage). Disabled when `prefers-reduced-motion` is set.

## 6. Entry Files

### `vite.config.js`
```js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
})
```

### `src/main.jsx`
```jsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { BrowserRouter } from 'react-router-dom'
import './index.css'
import App from './App.jsx'

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>
)
```

### `src/App.jsx` — Routes
```jsx
function Landing() {
  return <><Navbar /><Hero /><HowItWorks /><Features /><Stats /><About /><CTA /><Footer /></>
}

function App() {
  return (
    <Routes>
      <Route path="/" element={<Landing />} />
      <Route path="/auth" element={<AuthPage />} />
      <Route path="/forgot-password" element={<ForgotPassword />} />
      <Route path="/app" element={<AppShell />}>
        <Route index element={<Navigate to="/app/analyze" replace />} />
        <Route path="analyze" element={<AnalyzePrescription />} />
        <Route path="pricing" element={<PricingComparisons />} />
        <Route path="know" element={<KnowYourPrescription />} />
      </Route>
    </Routes>
  )
}
```

## 7. Pages & Components

### Landing Page (`/`)

**Navbar** (`Navbar.jsx`)
- Fixed to top (`position: fixed`, full width, `z-50`)
- Transparent at top; on scroll past 24px → frosted glass (`backdropFilter: blur(18px)` + dark background + sage bottom border)
- Left: prescription SVG icon + "Parchi." wordmark → links to `/`
- Center: "How it works" (anchor `#how-it-works`), "About Us" (anchor `#about`)
- Right: "Sign in / Sign up" outlined pill → `/auth`
- Mobile: hamburger icon

Scroll detection pattern:
```jsx
const [scrolled, setScrolled] = useState(false)
useEffect(() => {
  const onScroll = () => setScrolled(window.scrollY > 24)
  window.addEventListener('scroll', onScroll, { passive: true })
  return () => window.removeEventListener('scroll', onScroll)
}, [])
```

**Hero** (`Hero.jsx`)
- Starts with `pt-40` to clear the fixed navbar
- Full-screen section with WebGL Grainient background
- Left: glitch "PARCHI" title, Urdu tagline, CTA button → `/auth`, trust strip (Zero data · Native Urdu · WHO)
- Right: phone mockup with prescription card + animated "receipt flies in" (GSAP)
- GSAP animations use `once: true` + `onEnter` pattern to avoid React StrictMode double-run

**HowItWorks** (`HowItWorks.jsx`)
- Section `id="how-it-works"`
- 3 dark cards — no connecting line between them

**Features** (`Features.jsx`)
- 4 cards in a 2×2 grid
- Cards: Prescription Explained (sage), Affordable Alternatives (coral), Clinical Evidence (blue), Test Report Reader (purple)
- Each card: icon, badge, title, Urdu subtitle, description, checklist bullets

**Stats** (`Stats.jsx`)
- Pain statement + 4 stat tiles + 4 trust items

**About** (`About.jsx`)
- Section `id="about"`
- Left: story paragraphs + Urdu pull-quote with sage left border
- Right: 2×2 values grid

**CTA** (`CTA.jsx`)
- Single "Get started free →" button → `/auth`

**Footer** (`Footer.jsx`)
- Minimal; copyright centered and bottom-aligned

### Auth Flow

**AuthPage** (`/auth`) (`AuthPage.jsx`)
- Two panels: left brand panel (desktop only, `hidden lg:flex`) + right form panel
- Tab switcher: Sign In / Sign Up
- Sign In: Email + Password + Forgot Password link
- Sign Up: Full Name + Email + Password + Confirm Password
- Form `onSubmit` navigates to `/app/analyze` (mocked — no real API call)
- Password fields have show/hide toggle
- Mobile: left panel hidden, logo appears above form

```jsx
const navigate = useNavigate()
// form onSubmit:
(e) => { e.preventDefault(); navigate('/app/analyze') }
```

**ForgotPassword** (`/forgot-password`) (`ForgotPassword.jsx`)
- Two states: email input form → confirmation screen
- Confirmation shows the entered email address
- "Try again" resets back to form
- "Sign in" link → `/auth`

**AppShell** (`AppShell.jsx`)
- Full-height layout (`h-screen overflow-hidden`)
- Desktop: fixed left sidebar (`w-[220px]`) with logo, "Tools" nav section, user avatar + sign out
- Mobile: top header bar (logo + avatar) + bottom tab nav (3 icons)
- `<Outlet />` renders the active child route
- Sign out → navigates to `/`

Nav items:

  { to: '/app/analyze', label: 'Analyze', icon: <camera svg> },

- Idle: dashed upload zone (drag-and-drop), Take Photo + Upload File buttons, privacy note

## 8. Key Patterns

### GSAP + StrictMode
StrictMode runs effects twice in dev. Pattern used to avoid double-animation:

```jsx
ScrollTrigger.create({
  trigger: el,
  once: true,
  onEnter: () => {
    gsap.fromTo(el, { opacity: 0, y: 40 }, { opacity: 1, y: 0, duration: 0.7 })
  }
})
```

### WebGL Background (Grainient)
`src/components/Grainient/Grainient.jsx` uses the `ogl` library to render a full-screen WebGL shader with animated color blobs. Used in the Hero section as `<Grainient />` behind all content.

### Tailwind v4 Custom Values
No `tailwind.config.js`. CSS variables are used directly in class names:
```jsx
className="text-[var(--cream)] bg-[var(--bg-card)]"
```
Arbitrary values with `[]` syntax throughout.
